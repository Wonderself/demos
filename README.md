# Demos

Page d’accueil des démos WonderSelf.

Produit, pas monolithe :

- **CineGeny** — studio film IA
- **Regis** — orchestrateur
- **AISmad** — OS RAG-able
- **Apptiv** — carrière
- **MMax** — sports de combat
- **Trapeze** — jeu

Une page statique. Zéro build. Zéro secret.

## URLs

Éditer l’objet `LINKS` dans `index.html`.
Seul CineGeny est branché pour l’instant (`https://www.cinegeny.com`).

## Local

Ouvrir `index.html` dans un navigateur, ou :

```bash
python3 -m http.server 4173
```

## GitHub Pages

Repo Settings → Pages → Deploy from branch `main` / `/`
URL attendue : `https://wonderself.github.io/demos/`

Domaine custom plus tard : fichier `CNAME` + DNS.
Ne pas poser ça sur `cinegeny.com` : les trois marques restent séparées.
